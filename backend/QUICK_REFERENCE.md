# Quick Reference - Restructured Backend

## 🔧 Common Tasks

### Create a New Feature (e.g., "Employees")

```bash
# 1. Create entity
Core/Entities/Employee.cs

# 2. Create repository interface
Core/Interfaces/IEmployeeRepository.cs

# 3. Create DTOs
Application/DTOs/Request/CreateEmployeeRequestDto.cs
Application/DTOs/Response/EmployeeResponseDto.cs

# 4. Create validator
Application/Validators/CreateEmployeeRequestValidator.cs

# 5. Create service interface & implementation
Application/Services/Interfaces/IEmployeeService.cs
Application/Services/Implementation/EmployeeService.cs

# 6. Create repository implementation
Infrastructure/Repositories/EmployeeRepository.cs

# 7. Create EF configuration
Infrastructure/Data/Configurations/EmployeeConfiguration.cs

# 8. Update DbContext
Infrastructure/Data/Context/ApplicationDbContext.cs
# Add: public DbSet<Employee> Employees { get; set; }

# 9. Create controller
Presentation/Controllers/EmployeesController.cs

# 10. Register services in Program.cs or DI config
services.AddScoped<IEmployeeRepository, EmployeeRepository>();
services.AddScoped<IEmployeeService, EmployeeService>();
```

### Add a Database Migration

```bash
# Navigate to project folder
cd backend/SLBFE.HRM.API

# Add migration
dotnet ef migrations add MigrationName

# Update database
dotnet ef database update
```

### Build & Run

```bash
# Build
dotnet build

# Run
dotnet run

# Watch mode (auto-restart on changes)
dotnet watch run
```

## 📝 Naming Conventions

- **Entities**: Singular noun → `Employee.cs`
- **Interfaces**: Prefix 'I' → `IEmployeeRepository.cs`
- **DTOs**: Descriptive suffix → `CreateEmployeeRequestDto.cs`
- **Controllers**: Plural + Controller → `EmployeesController.cs`
- **Services**: Singular + Service → `EmployeeService.cs`
- **Validators**: DTO name + Validator → `CreateEmployeeRequestValidator.cs`

## 🔀 Namespace Pattern

`SLBFE.HRM.API.{Layer}.{Folder}.{SubFolder}`

Examples:
```csharp
SLBFE.HRM.API.Core.Entities
SLBFE.HRM.API.Application.Services.Implementation
SLBFE.HRM.API.Infrastructure.Repositories
SLBFE.HRM.API.Presentation.Controllers
```

## 💡 Pro Tips

- ✅ Always inherit from `BaseEntity` for entities
- ✅ Use `BaseApiController` for controllers
- ✅ Return `Result<T>` from services
- ✅ Use DTOs for all API requests/responses
- ✅ Validate requests with FluentValidation
- ✅ Keep controllers thin (delegate to services)
- ✅ Use dependency injection everywhere
- ✅ Write tests for each layer independently
