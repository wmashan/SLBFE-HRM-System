# Employee Reports - Quick Start Guide

## How to Generate Reports

### Step 1: Access the Reports Feature
1. Navigate to the **HR Manager Dashboard**
2. Go to the **Employees** section
3. Click the purple **"Reports"** button in the top-right action bar

### Step 2: Choose Your Report Type
The reports modal opens with three tabs:

#### **Predefined Reports Tab** (Recommended for beginners)
- **Employee Summary Report**: Complete overview of all employees
- **Demographics Analysis**: Age, gender, and diversity insights
- **Department-wise Analysis**: Employee breakdown by departments
- **Salary Analysis**: Compensation analytics (when data available)
- **Education & Qualifications**: Academic and certification analysis
- **Service Tenure Report**: Employee tenure and service duration
- **Promotion Analysis**: Career progression patterns
- **New Joiners Report**: Recent hires within date ranges
- **Birthday List**: Employee birthday listings
- **Employee Directory**: Complete contact information

#### **Custom Reports Tab** (Coming Soon)
- Create custom reports with specific fields and filters
- Advanced configuration options
- Reusable report templates

#### **Report History Tab**
- View previously generated reports
- Download existing reports
- Manage report archives

### Step 3: Configure Your Report
1. Click on any predefined report card to select it
2. Review the report configuration:
   - **Output Format**: PDF, Excel, CSV, or JSON
   - **Include Charts**: Visual analytics and graphs
   - **Group By**: Department, branch, age group, etc.
   - **Sort By**: Name, join date, department, etc.
   - **Included Sections**: Data fields to include

### Step 4: Generate the Report
1. Click the blue **"Generate Report"** button
2. Wait for the processing to complete (usually 1-3 seconds)
3. Review the **Report Summary** that appears:
   - Total employees included
   - Key statistics and metrics
   - Department and branch breakdowns
   - Demographics insights

### Step 5: Download Your Report
1. Click the green **"Download Report"** button
2. The file will be saved to your default downloads folder
3. File format depends on the report configuration (Excel, PDF, etc.)

## Tips for Better Reports

### 🎯 **Choosing the Right Report Type**
- Use **Employee Summary** for general overviews
- Use **Demographics Analysis** for diversity reporting
- Use **Department-wise** for organizational planning
- Use **Service Tenure** for retention analysis

### 📊 **Understanding Charts**
- **Pie Charts**: Show proportional distributions (departments, gender)
- **Bar Charts**: Compare quantities across categories (age groups)
- **Doughnut Charts**: Similar to pie charts with better readability

### 🔍 **Using Filters Effectively**
- Current employee filters automatically apply to reports
- Use age ranges for targeted demographic analysis
- Filter by departments for focused reporting
- Use date ranges for time-based analysis

### 💾 **Managing Report Files**
- Reports are automatically saved with timestamps
- Use descriptive names when saving for easy identification
- PDF files are better for presentations and sharing
- Excel files allow for further data manipulation

## Keyboard Shortcuts

- **Esc**: Close the reports modal
- **Enter**: Generate selected report (when report is selected)
- **Tab**: Navigate between report cards

## Troubleshooting

### Common Issues:

#### **Report Generation Fails**
- Check your internet connection
- Refresh the page and try again
- Contact IT support if the issue persists

#### **Download Doesn't Start**
- Check if your browser blocks downloads
- Ensure popup blockers are disabled for the site
- Try a different browser if issues continue

#### **Empty or Incomplete Reports**
- Verify that employee data exists for the selected filters
- Check if current filters are too restrictive
- Clear filters and try generating again

#### **Charts Not Displaying**
- Ensure your browser supports HTML5 canvas
- Update your browser to the latest version
- Check if JavaScript is enabled

### Performance Tips:

#### **For Large Employee Datasets (500+ employees)**
- Use specific date ranges to limit data
- Filter by department or branch for focused reports
- Generate reports during off-peak hours
- Consider multiple smaller reports instead of one large report

#### **Optimal Report Formats**
- **Excel**: Best for data analysis and manipulation
- **PDF**: Best for sharing and presentations
- **CSV**: Best for importing into other systems
- **JSON**: Best for technical integrations
